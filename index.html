About This Project

This application is built with plain HTML and CSS for the interface and pure Java for the backend. The detection logic uses a transparent, rule-based scoring model inspired by Naive Bayes: every spam indicator contributes points, the total is normalised into a percentage, and the email is classified as Spam, Suspicious or Not Spam.

  • No JavaScript, no database, no external libraries.
  • All input is validated and HTML-escaped before display.
  • Nothing is stored — each request is analyzed and discarded.
